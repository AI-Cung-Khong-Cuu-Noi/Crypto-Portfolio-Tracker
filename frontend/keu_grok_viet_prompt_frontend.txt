API Holdings
GET /portfolios/:id/holdings (JWT)
Chỉ portfolio của user hiện tại.
Gom giao dịch theo thời gian, tính số lượng còn lại, cost basis USD, giá hiện tại, change24h, giá trị, unrealized P&L.
summary: totalCostBasisUsd, totalMarketValueUsd, totalUnrealizedPnlUsd, symbolsMissingPrice (coin không map được giá).
Logic tổng hợp
backend/scr/services/holdings.service.ts: aggregateHoldingsFromTransactions + enrichHoldingsWithMarket
BUY: tăng số lượng + cost (ưu tiên totalValue, không thì amount * price + fee)
SELL: trừ theo giá vốn bình quân
TRANSFER: bắt buộc transferDirection: IN / OUT (IN cộng qty/cost, OUT giống rút vốn theo avg cost)
Giá thị trường
backend/scr/utils/coingecko.util.ts: map symbol → CoinGecko id (bảng tĩnh phổ biến + search), gọi /simple/price (USD + 24h change).

Đã triển khai mục 2.5 – Dashboard & phân tích (bước tiếp theo sau Holdings/Transactions trong mo_ta.md).
 
API (JWT, prefix /dashboard)
Method          Path    Mô tả
GET    /dashboard/summary           Query portfolioId? — tổng giá trị, cost basis, unrealized + realized P&L, totalPnlUsd, số portfolio, top 5 gainers/losers trong holdings của bạn
GET    /dashboard/allocation          Query portfolioId? — phân bổ theo valueUsd + % (pie chart)
GET    /dashboard/performance     Query portfolioId?, days (mặc định 30, tối đa 365) — điểm theo ngày: totalMarketValueUsd + totalCostBasisUsd (có note về cách ước tính)
GET    /dashboard/trend      Query perPage (mặc định 10) — top tăng/giảm mạnh 24h toàn thị trường (CoinGecko coins/markets)
Logic chính
holdings.service.ts: aggregatePositionsAndRealized() — P&L realized khi SELL (proceeds − cost bình quân đã bán). aggregateHoldingsFromTransactions() giờ gọi hàm này và chỉ lấy positions.
dashboard.service.ts: lookup giá theo symbol, chuỗi performance (giá spot tại thời điểm gọi API áp lên số dư lịch sử — có note trong response).

Đã triển khai 2.7 Báo cáo & Thống kê (API JSON). Export PDF/Excel trong mo_ta.md thuộc giai đoạn 3 nên chưa làm.
 
API mới — /reports (JWT)
Method          Path    Mô tả
GET    /reports/summary     Báo cáo theo ngày / tháng / năm (granularity: day | month | year, mặc định month). Query: portfolioId?, from?, to? (không gửi → cả năm UTC hiện tại). Mỗi bucket: tradeCount, buyVolumeUsd, sellVolumeUsd, realizedPnlUsd + totals.
GET    /reports/tax-realized Tax / realized P&L: từng lệnh SELL trong khoảng thời gian với proceedsUsd, costBasisUsd, realizedPnlUsd (cùng logic giá vốn bình quân như holdings). Có totalRealizedPnlUsd + description nhắc xác minh với kế toán.
GET    /reports/by-coin        Performance theo coin: khối lượng mua/bán, realized lifetime, số lệnh, transfer, vị thế mở (currentQuantity, costBasisUsd, …). Query includeMarket=true để thêm giá hiện tại / unrealized (CoinGecko). from/to (tùy chọn) để có thêm realizedPnlUsdInRange.
Logic & file

scr/swagger/schemas/reports.schemas.ts
